# figure-skating-ml-analysis
Анализ оценок Олимпийского фигурного катания (2006-2026): EDA, визуализация и ML-модели для прогнозирования баллов и попадания в Топ-10.

## Описание проекта
Проект посвящен анализу исторических данных выступлений фигуристов на Олимпийских играх (2006–2026 гг.). В рамках проекта проведен исследовательский анализ данных (EDA), визуализация трендов и построены модели машинного обучения для прогнозирования успеха спортсменов.

## Данные
Датасет взят с Kaggle: [Olympic Figure Skating Singles Scores (2006–2026)](https://www.kaggle.com/datasets/nupurgudigar/olympic-figure-skating-singles-scores-20062026).
В данных представлены оценки за технику (TES) и артистизм (PCS), а также итоговые места.

## Стек технологий
* **Язык:** Python
* **Библиотеки:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
* **Среда:** Google Colab

## Что было сделано
1. **EDA и визуализация:** Проанализирована динамика роста баллов с 2006 по 2026 год. Построены графики соотношения техники и артистизма.
2. **Регрессия:** Построена модель линейной регрессии и случайного леса для прогнозирования итогового балла (TSS). Лучшая точность (R2): **0.977**.
3. **Классификация:** Обучена модель для прогнозирования попадания фигуриста в Топ-10. Точность (Accuracy): **0.778**.
4. **Инференс:** Написана функция для ввода баллов (TES и PCS) с клавиатуры и получения прогноза в реальном времени.

## Ключевые выводы
* За 20 лет средний балл вырос, что связано с усложнением технических элементов.
* Оценки за технику и артистизм имеют сильную линейную связь с итоговым баллом.
* Модель классификации адекватно реагирует на современные тренды: для попадания в Топ-10 в 2026 году требуются значительно более высокие баллы, чем в 2010-х.

## Как запустить
Проект выполнен в Google Colab. Вы можете открыть ноутбук и запустить все ячейки (Run All). Данные загружаются автоматически по ссылке из Kaggle.
